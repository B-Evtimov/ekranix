# Ekranix

Безжично споделяне на екрана на компютъра към Android TV с минимално забавяне.

- **PC приложение** (Windows, C#/.NET, WPF): открива телевизорите в мрежата, сдвоява се с код и стриймва екран/приложение и звук.
- **TV приложение** (Android TV, Kotlin): показва код за сдвояване и възпроизвежда потока с хардуерен декодер.

> В процес на разработка.
